## 先认识它

AsterDrive 是一个基于 Rust 和 React 的轻量自托管云盘。你可以从默认 SQLite + 本地存储的单机部署开始，之后按需要接入 PostgreSQL / MySQL、S3 兼容对象存储、Azure Blob Storage、腾讯云 COS、Microsoft Graph 支持的 OneDrive / SharePoint drive、SFTP 文件服务器、团队空间、WebDAV、WOPI 在线预览编辑，以及远程从节点存储。

它不是完整协作套件，当前重点是把个人和小团队的文件管理、分享、上传、预览、存储策略和日常运维路径做清楚。多实例部署已经支持在共享 PostgreSQL / MySQL、Redis 和共享存储之上运行多个 Primary，但它仍不是一套替你管理数据库、Redis、对象存储和跨区域复制的完整集群编排系统，准确边界见 [关于 AsterDrive](/reference/about/)。

## 按目的走

### 我只是想先跑起来

从 [快速开始](/start/quick-trial/) 走一遍。它会带你完成启动服务、创建第一个管理员、上传文件、试分享、检查 WebDAV 和跑一轮基础验收。

如果你已经决定正式部署，直接看 [部署概览](/deploy/)。那一组文档会把 Docker、systemd、反向代理、上线检查、升级和备份放在同一条线上讲清楚。

### 我已经登录了，想知道怎么用

从 [使用指南](/start/) 进入。普通用户优先看 [用户手册](/using/) 和 [常用流程](/start/common-workflows/)，单独问题再跳到团队权限、分享、编辑、在线预览、上传或 WebDAV。

### 我要管一个实例

先看 [管理后台](/admin/)，再看 [配置总览](/reference/config/)。AsterDrive 的配置分成启动配置、后台运行时设置、存储策略、策略组、存储策略后端和外部网络环境，按层看会清楚很多。

如果你正在接新的存储策略后端，看 [存储策略后端](/admin/storage-backends/)。

### 我要按后端模块找文档

用户文档按读者任务组织，不再按后端模块组织。要定位"这个能力归哪个模块管"，看开发者文档的 [架构概览](https://drive.docs.astercosm.com/developer/architecture/) 和 [后端服务所有权](https://drive.docs.astercosm.com/developer/architecture/backend-service-ownership/)。

### 我要上线或排障

上线前按 [部署概览](/deploy/) 选方式，再补 [反向代理](/deploy/reverse-proxy/)、[首次启动检查](/ops/first-check/)、[生产上线检查](/ops/launch-checklist/)、[备份与恢复](/ops/backup/)。已经出问题就直接去 [故障排查](/ops/troubleshooting/)，看到错误码再配合 [错误码处理](/reference/errors/)。

### 我看不懂某个词，或者不知道该查哪里

先看 [术语表](/reference/glossary/) 和 [常见问题速查](/reference/faq/)。这两页不是让你从头读的，是让你少走弯路的。
