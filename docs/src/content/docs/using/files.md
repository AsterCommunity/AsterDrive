## 文件页面最常用的位置

- 左侧工作空间列表：切换个人空间或团队空间
- 左侧目录树：快速进入目标文件夹
- 顶部搜索框：搜索当前工作空间里的文件和文件夹
- `回收站`：处理当前工作空间里的已删除内容
- `我的分享`：查看当前工作空间里已经发出去的链接
- `任务中心`：查看在线压缩、在线解压、打包下载等后台任务
- `WebDAV`：创建当前工作空间的桌面客户端账号；个人空间和团队空间分别管理各自的账号
- 右上角用户菜单里的 `设置`：调整个人资料、界面、安全和团队相关设置

## 整理文件

文件列表、右键菜单和顶部操作区可以完成大多数日常工作：

- 创建文件夹
- 创建空白文本文件
- 上传文件
- 上传文件夹
- 从 HTTP/HTTPS 链接导入文件
- 下载文件
- 重命名、复制、移动、删除文件和文件夹
- 查看详细信息
- 管理标签
- 手动锁定或解锁文件
- 在线压缩、在线解压和文件夹打包下载
- 在列表视图和网格视图之间切换
- 按名称、大小、创建时间、更新时间或类型排序

你也可以直接拖拽：

- 把文件或文件夹拖到左侧目录树里的目标文件夹
- 把文件或文件夹拖到顶部面包屑里的上级目录
- 把文件或文件夹拖到左侧的回收站

## 搜索、多选和批量处理

顶部搜索框会在当前工作空间里按名称搜索文件和文件夹。可以直接点搜索框，也可以用 `Ctrl + K` 打开搜索面板；面板里能切换"全部 / 仅文件 / 仅文件夹"，按图片、视频、音乐、文档、表格、演示、压缩包、代码和其他分类快速筛选，也能选择一个或多个标签。

输入关键词或选好筛选条件后，按 `Enter` 或点 `搜索` 会进入当前工作空间的搜索结果页。结果页里可以继续打开文件、进入位置、查看信息或执行可用操作，不会把团队空间和个人空间的结果混在一起。

标签筛选有两种模式：

- `匹配任一`：文件或文件夹带有选中的任意一个标签就会出现
- `匹配全部`：必须同时带有所选全部标签才会出现

左侧也有常用类型的快速入口，例如图片、视频、音乐和文档。点进去本质上还是在当前工作空间里按文件分类搜索。

需要一次处理多个项目时，可以直接多选后批量执行：

- 批量移动
- 批量复制
- 批量删除
- 批量打包下载

在文件列表和回收站里都可以使用 `Ctrl + A` 或 `Cmd + A` 全选当前页。

### 在不同工作空间之间复制或移动

复制或移动时，目标位置选择框可以切换工作空间。常见用法是：

1. 在当前工作空间选中文件或文件夹。
2. 点击 `复制到` 或 `移动到`。
3. 选择目标工作空间，再打开目标文件夹。
4. 点击确认按钮完成操作。

复制会保留原来的文件；移动成功后，原来的文件会进入源工作空间的回收站。文件夹会连同里面的内容一起处理。

需要留意：

- 你必须同时能访问源工作空间和目标工作空间。
- 目标空间没有足够容量时，移动不会删除源文件。
- 被锁定的文件或文件夹不能跨工作空间移动。
- 目标位置已经有同名项目时，系统会自动在新项目名称后加上副本编号。
- 一次选择了多个项目时，页面会显示成功和失败的数量；遇到失败项目，先刷新源空间和目标空间再继续处理。
- 移动到同一个工作空间时，仍然只是普通的目录移动，不会创建新的副本。

## 标签怎么用

标签属于当前工作空间。个人空间里的标签不会自动出现在团队空间里，不同团队之间的标签库也彼此独立。

你可以在文件或文件夹的右键菜单、操作菜单或详细信息里管理标签：

- 给一个文件或文件夹添加、移除标签
- 选中多个项目后批量添加或移除标签
- 打开 `标签库` 创建、重命名、改色或删除标签
- 在搜索里按标签过滤结果

如果搜索标签时没有匹配项，可以直接创建新标签。创建后还要确认当前项目的标签变更，页面提示"已保存"后才算真正写入。

删除标签会把它从当前工作空间里所有使用它的文件和文件夹上移除；它不会删除文件本身。只是想从某几个文件上拿掉标签时，用"移除标签"，不要删除标签库里的标签。

## 详细信息里有什么

文件或文件夹的"详细信息"会显示名称、大小、占用空间、类型、创建时间、修改时间、锁定状态、分享状态和存储策略 ID 等信息。排查"这个文件到底在哪条策略上""是不是被锁住了"时，先看这里。

这里的"大小"和"占用空间"不是同一个概念：

- 文件大小是当前文件本身的大小
- 文件占用空间会把历史版本占用一起算进去
- 文件夹占用空间会递归统计这个文件夹下面所有内容的占用，适合找出哪个目录最占配额
