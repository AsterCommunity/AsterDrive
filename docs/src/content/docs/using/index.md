欢迎使用 AsterDrive ✨

这一分区是给**普通用户**看的——拿到账号、登录进来、上传第一个文件、分享给别人、必要时找回回收站里的内容。不需要按顺序读完，看到哪一块不清楚，直接翻对应任务页。

如果你是管理员，建议先从这里了解普通用户视角，再看 [管理实例](/admin/)。

## 我们对"好用"的定义

AsterDrive 不追求"功能最多的网盘"。我们想做的是这样一个东西：

- **常用的事不让你想** —— 上传、找文件、分享、误删恢复，都该是一次操作完成
- **不出意外的事不打扰你** —— 没必要的提示、没必要的对话框、没必要的"你确定吗"都尽量去掉
- **真出问题时给你清晰的信号** —— 错误码 + 中文提示 + 可操作的下一步建议

如果你用下来觉得哪里别扭，[开个 issue 告诉我们](https://github.com/AsterCommunity/AsterDrive/issues)——这是最直接的反馈方式。

## 一个心智模型：工作空间

登录后先记住一件事：**所有内容都跟着当前工作空间走**。

- `我的空间`：你的个人文件、个人分享、个人回收站和 WebDAV 账号
- 团队空间：加入团队后才会出现；每个团队空间有自己的文件、分享、回收站和任务列表

搜索、分享、任务和回收站都只看当前工作空间。排查"为什么我看不到某个文件 / 分享 / 任务"时，第一步永远是：先确认自己当前在哪个工作空间。详见 [工作空间与团队](/using/workspaces-teams/)。

## 登录和首次进入

登录页不需要你先决定"这是登录还是注册"。输入用户名或邮箱后，页面会自动判断流程：

- 系统里还没有任何用户：创建管理员
- 输入的是已有账号：登录
- 输入的是新账号，而且管理员允许公开注册：注册普通账号

第一个创建成功的账号会自动成为管理员；后续新注册的普通账号，通常需要先点激活邮件才能登录。更多登录方式（MFA、Passkey、外部认证）见 [账号与安全](/using/account-security/)。
