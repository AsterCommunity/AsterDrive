:::tip[这一篇讲什么]
两类"后悔药"：误删的文件去回收站找，改坏的内容去版本历史找。
:::

## 回收站

普通删除不会立刻彻底清除文件或文件夹，而是先进入回收站。

你可以在回收站中：

- 恢复项目
- 永久删除单个项目
- 清空整个回收站
- 批量恢复
- 批量永久删除

如果原来的父目录已经不存在，恢复时项目会回到根目录。

清空整个回收站会创建一个后台任务，而不是把页面卡住等它同步删完。确认清空后，到当前工作空间的 `任务中心` 看 `回收站清空` 任务进度；团队空间的回收站清空任务也只会出现在对应团队空间的任务中心里。

回收站跟着当前工作空间走。个人空间删掉的内容在个人空间回收站，团队空间删掉的内容在对应团队空间回收站。

:::tip[回收站保留多久]
回收站保留天数由管理员在系统设置里控制。超过保留期的项目会被自动清理，清理后无法恢复。
:::

## 版本历史

只要发生覆盖写入，就会生成历史版本。常见来源包括：

- 浏览器内文本编辑
- WOPI 在线保存
- WebDAV 覆盖保存
- 其他直接覆盖原文件内容的写入方式

你可以在版本历史里：

- 查看旧版本
- 恢复某个旧版本
- 删除不需要的旧版本

:::caution[恢复会截断之后的版本]
恢复旧版本后，那个版本之后的新版本记录会被一起截断，所以恢复前先确认。
:::

如果保存时出现冲突提示，通常说明这份文件在你打开后又被别人改过了。先刷新内容，再决定是否继续保存。

历史版本保留数量由管理员控制。版本占用会算进文件的"占用空间"，在文件详细信息里可以看到，见 [文件与整理](/using/files/#详细信息里有什么)。
