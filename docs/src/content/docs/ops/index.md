## 什么时候该压测

改存储后端、调后台任务并发、评估版本回归时，用仓库自带的 k6 基准在自己的环境跑一轮：[性能基准与压测](/ops/capacity/benchmarking/)。容量估算需要的实测输入（p95、吞吐、内存占用）也从这里来。
