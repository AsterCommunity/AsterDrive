## 部署与上线

| 场景 | 一句话 | 权威页 |
| --- | --- | --- |
| 新部署后的第一次管理员检查 | 按后台入口顺序过一遍：概览、用户、团队、存储策略、策略组、任务、系统设置、WebDAV | [首次启动检查](/ops/first-check/) |
| 正式上线前验收 | 数据目录、HTTPS、公开站点地址、监控、备份、回滚预案逐项确认 | [生产上线检查清单](/ops/launch-checklist/) |
| 命令行离线检查 | `aster_drive doctor` 跑一轮部署体检 | [运维 CLI](/ops/cli/) |

## 存储与上传

| 场景 | 一句话 | 权威页 |
| --- | --- | --- |
| 给不同用户或团队安排存储路线 | 先建存储策略，再在策略组里配大小分流规则，最后绑到用户或团队 | [存储策略与策略组](/admin/storage-policies/) |
| 给远程节点准备存储 | enroll 之后还要创建默认远程存储目标，否则上传会被拒 | [Follower 存储节点](/deploy/follower-node/) |
| 大文件上传中断续传 | 回到原文件夹重新选同一个文件，会话未过期就会续传 | [上传与下载](/using/upload-download/) |
| 上传失败排查 | 先查工作空间和策略组，再查大小上限、代理、CORS、配额 | [上传与下载](/using/upload-download/) |

## 协作与分享

| 场景 | 一句话 | 权威页 |
| --- | --- | --- |
| 创建团队空间 | 系统管理员在 `管理 -> 团队` 创建并指定初始管理员和策略组 | [用户与团队](/admin/users-teams/) |
| 发资料给别人 | 切到正确工作空间后创建分享，按需设密码、过期时间和下载次数 | [分享与公开访问](/using/sharing/) |
| 给 Office 文件接在线打开方式 | 填对公开站点地址后在预览应用里导入 WOPI Discovery | [预览与文件处理](/admin/preview-processing/) |
| 给设备创建 WebDAV 账号 | 每台设备一个独立账号，丢失时单独停用 | [WebDAV 使用](/using/webdav/) |

## 出问题的时候

| 场景 | 一句话 | 权威页 |
| --- | --- | --- |
| 处理误删 | 先去回收站恢复；清空回收站是后台任务 | [回收站与版本](/using/recycle-bin/) |
| 文件一直被锁定 | 先让编辑者正常保存退出，异常残留锁由管理员到 `管理 -> 锁` 清理 | [预览与编辑](/using/preview-editing/) |
| 缩略图不符合预期 | 按任务失败记录、处理器开关、后缀绑定、测试命令、源大小上限顺序查 | [预览与文件处理](/admin/preview-processing/) |
| 其他症状 | 按症状索引定位 | [故障排查](/ops/troubleshooting/) |
